# IoT Uncertainty Quantification

This project integrates Boolean SAT solvers and probabilistic models to quantify uncertainty in IoT sensor data.

## Features

- Models sensor reliability with logical constraints
- Uses SAT solvers to determine possible states
- Applies Gaussian probability models to quantify likelihoods

## Example

```python
from iot_uncertainty.sat.constraint_solver import ConstraintSolver
from iot_uncertainty.prob.probability_model import ProbabilityModel
```
